# Multi-Step Form Builder

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Build Status](https://img.shields.io/badge/build-passing-brightgreen)

A lightweight, flexible, and customizable Multi-Step Form Builder. This tool allows developers to create complex, multi-stage user journeys with built-in validation, progress tracking, and state management.

## 🚀 Features
- **Drag & Drop Builder**: Questions and forms can be managed by the drag and drop builder.
- **Dynamic Step Management**: Easily add, remove, or reorder steps.
- **State Persistence**: Keeps form data intact as users move between steps.
- **Form Validation**: Integrated validation for each individual step.
- **Progress Indicator**: Built-in progress bar or step-count indicator.
- **Conditional Logic**: Show or hide steps based on previous user input.
- **Responsive Design**: Fully mobile-friendly UI.
- **Headless or Styled**: Can be used as a logic-only hook or with the provided UI components.

## 🛠️ Tech Stack

- **PHP**
- **jQuery**
- **TailwindCSS**
- **Wordpress**
